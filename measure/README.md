# Измерения Guitar Suite (Audition 3.0) — скрипты и результаты

Данные измерений (wav) хранятся у пользователя: папки `GuitarSuite_tests_44.1k` (основная) и `GuitarSuite_tests_48k`.
Скрипты: `python3 -I analyze.py <папка_44.1k> ../GuitarSuiteData.h` — все блоки; `export_header.py` — генерация `GuitarSuiteData.h`
из `results44/`; `comp_fit*.py` — подбор динамики компрессора по траектории гейна («оракул», окно 0,25 мс).

## Выводы (2 ноября 2026)
- Box 9, Fuzz, Filter — сняты точно (−143 / −100 / −47 дБ). Компрессор — чистый гейн (оракул −59 дБ), модель даёт −26 дБ на голосе.
- Лучшая структура компрессора: пиковый детектор (мгновенная атака, релиз ~4,5–5,4 мс) → hard-knee → одно‑полюсное сглаживание
  линейного гейна (атака ~11 мс, релиз ~65–90 мс). Ошибка гейна 0,43 дБ RMS; остаток — медленное блуждание ±0,3 дБ (5–20 Гц), без ряби.
- Проверено и отвергнуто (хуже): RMS‑детекторы (оконный, одно‑полюсный), пик с холдом, двухступенчатое сглаживание (лучше на ступенях,
  хуже на голосе), сглаживание огибающей вместо гейна, dB‑домен сглаживания. Блочной обработки нет (автокорреляция кривизны — только период тона).
- В гласной гейн Audition идёт идеально гладко (0,01 дБ / 0,3 мс), без реакции на пики периодов — у модели лёгкие ступеньки. Идеи на будущее:
  детектор на предварительно отфильтрованном сигнале, асимметрия +/− полуволн, мягкое колено / зависимость ratio от уровня, слежение за средним |x|.
- 48 кГц: Audition сам ресемплит 44,1‑ядро кабинета (задержка 24 отсч., пре‑звон, обрезка хвоста). Плагин воспроизводит 44,1‑поведение
  на всех частотах (решение пользователя, вариант А).
